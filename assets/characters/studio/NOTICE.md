# CHS character studio

Original generated full-body illustrations for Alex and Maya, created for this project on 2026-10-16. Source: `/workspace/generated_images/exec-9bcc73ab-59b8-4554-b20f-42f592fade9c.png` (1024 × 1536). Converted to transparent WebP at quality 95 without overwriting the source. These illustrations replace the old modular/NoEdge renders in the current character picker. They are not derivatives of the licensed NoEdge input models. Existing third-party assets and their notices remain in their original folders for compatibility; no attribution is removed from those files.
